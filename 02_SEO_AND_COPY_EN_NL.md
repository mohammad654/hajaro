# SEO tags and website text (English + Dutch)

For a bodybuilding and personal trainer website.

**How to use:** Replace every `[PLACEHOLDER]` with a real value. Anything marked `[CONFIRM: ...]` is only allowed on the site if it is true. Delete the line if it is not. Nothing here is a claim about the trainer; it is a template written to be filled in with real facts.

Placeholders: `[NAME]` trainer name, `[CITY]` city, `[REGION]` province or region, `[DOMAIN]` website domain.

Limits used: title max 60 characters, meta description max 155 characters (checked with a sample name and city, so shorten if your name or city is long).
